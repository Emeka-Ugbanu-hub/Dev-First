## Three speeds, automatically

- **Questions** get answered right in chat — file paths are clickable.
- **Trivial changes** (one step, unambiguous) just run, with a checkpoint so you can undo.
- **Everything else** gets a plan card with steps, tradeoffs, and a **GO ON** button. Nothing is touched until you approve.

[Open Dev-First](command:devFirst.openChat)

Select code and hit `Cmd+Alt+E` to explain it, or use the lightbulb for Fix and Improve.
