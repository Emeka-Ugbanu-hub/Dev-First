# Changelog

## 0.1.0

Initial release.

- Plan-first workflow: every change request becomes a plan you approve before a single line changes; simple, single-step changes run directly.
- Agent tools: file read/write/edit with fallback application, terminal with approval and sandboxing, background processes, web search/fetch, browser automation, MCP client, memory, skills, todos, and subagents.
- Multi-provider support: OpenAI-compatible, Anthropic, and Gemini with multiple connected providers and one-key-per-provider switching.
- Reasoning controls: adaptive effort per task, model-managed reasoning, and per-provider native adaptive modes.
- Open-file scanning: deterministic rules plus tree-sitter analysis across many languages, with instant squiggles and hover explanations.
- Cross-file intelligence: duplication, dependency, contract, security, and storage checks with clickable findings.
- Learning layer: plan concepts and risks, evidence-based explanations, completion takeaways, project conventions, and verified learning resources.
- Architecture map: concept-first drill-down of the real codebase, with package-aware domains and relationship edges.
- Diff review: per-file accept/reject, run history with viewable diffs, checkpoints, and revert/redo.
- Sessions: tabs, history, search, transcript export, context compaction with deterministic pruning, and a live context bar.
- Privacy: bring your own key, local scanning, no telemetry.
